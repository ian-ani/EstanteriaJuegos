## About

A desktop program developed with Java that allows you to keep track of your physical (or digital!) collection. 
Tested on **Windows 10**.

## Features

- **Add** games to your collection
- **View and edit** games of your collection
- **Delete** games of your collection
- **Search** games by name or platform
- **Sort alphabetically** by name, platform, status, tags (genre), personal opinion or notes
- **Duplicates not allowed**: it's considered a duplicate if both name and platform match
- Max **three tags** for game
- UI **available in Spanish and English**
- **Export** your collection to a CSV file

## Data storage

- Uses **SQLite** due to its easy configuration and its lightweight nature
- Data base schema is in Spanish
- Data are stored locally
- Collection may be exported to CSV via this program

## Technologies used

- **JDK 24** (Oracle OpenJDK 24.0.2)
- **Java Swing**
- **SQLite**
- SQLite **JDBC driver** (v. 3.53.2.0)
- **GSON 2.10.1**

These technologies and libraries are only relevant to anybody that either wants to compile or develop this program further.
